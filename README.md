# Code as Diagrams & Diagrams as Code

## Project Overview
An AI-powered application developed using Python and Django
that converts source code into UML diagrams and generates
source code from diagram inputs.

## Features
- Code to UML diagram generation
- Diagram to code generation
- Generative AI integration
- Software documentation support

## Technologies
- Python
- Django
- Generative AI
- OpenAI GPT
- PlantUML
- HTML
- CSS

## How to Run
1. Clone the repository
2. Install the required dependencies
3. Configure the required environment variables
4. Run the Django development server
